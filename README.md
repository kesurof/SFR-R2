# Application web

Code source d'une application web auto-hébergée.

## Dépôt public de référence

Le dépôt public de référence est [github.com/kesurof/SFR-R2](https://github.com/kesurof/SFR-R2).

Les travaux doivent être réalisés depuis ce dépôt local, sur la branche `main`.
Les synchronisations et les push de livraison utilisent le remote `origin` associé
à cette URL.
